MythCool-mini v0.2.0
https://github.com/Axiomerator/MythCool-mini

VK N360 (374A:A017) screen-monitor companion for Windows x64.
Tested hardware: Ryzen 9 9950X, NVIDIA RTX 3080 Ti, Windows 11 x64.

1. Configure video and up to six monitor slots in official Myth.Cool first.
2. Exit official Myth.Cool from its tray menu.
3. Install the official signed PawnIO driver if CPU temperature/power is needed:
   https://pawnio.eu/
4. Run MythCool-mini.exe and approve Windows UAC. Double-click the tray icon for status.
5. Enable login autostart in the window/tray menu if wanted.

The application preserves device video playback and updates supported sensor text.
Video import/upload, conversion and layout editing still require official Myth.Cool.
Other cooler models, AMD/Intel GPUs and other CPU temperature/power backends are not supported/verified.

Data is created in data/ beside the EXE. Exit before upgrading; preserve data/.
After moving the application, enable autostart again to update its target.
Application files are portable; the signed PawnIO driver is a system installation.
