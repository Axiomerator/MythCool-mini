# MythCool-mini v0.2.0

首个公开发行版：面向 VK N360 的 C++20 / Win32 轻量监控续刷程序。

- 复用原版六槽布局，原版退出后续刷已启用的 CPU/GPU 参数。
- 亮度 0～100、息屏与恢复、原生托盘和状态页。
- 默认管理员启动，当前用户最高权限登录自启开关。
- 原创多尺寸图标，应用与托盘共用。
- 实机验证六项参数、视频与布局保持、亮度读回、注销后重新登录自启。

## 当前支持与依赖

实测：VK N360 374A:A017、Ryzen 9 9950X、NVIDIA RTX 3080 Ti、Windows 11 x64、原版业务版本 1.1.22.420。CPU 温度/功耗代码限定 AMD Family 1Ah / Model 44h，并依赖官方签名 PawnIO 驱动；NVML 使用现有 NVIDIA 驱动。

视频导入/转码/上传、布局编辑仍需官方 Myth.Cool。其他冷头、CPU 温度功耗、AMD/Intel GPU、多设备组合和 ARM64 尚未支持或验证。支持的指标列表与字段容量见 README 和 docs/SUPPORT.md。

本机 60 秒采样：私有提交约 28.7MiB、私有工作集约 26.0MiB、总工作集约 48.3MiB，整机 CPU 约 0.032%。对照原版历史 5 秒记录，私有提交低约 93.2%、CPU 样本值低约 97.1%；属于非同期历史对照，不是严格 A/B 基准。

下载 windows-x64.zip 后解压运行，按 UAC 提示授权。source.zip 为源码。PawnIO 安装器不在包内；链接见 README。升级前退出 mini，保留 data，移动位置后重新开启自启。

应用 MPL-2.0；第三方许可证和对应源码随包提供。ZIP 不含厂商软件、固件、NVIDIA 驱动或个人配置。SHA256 文件用于核对下载完整性。
