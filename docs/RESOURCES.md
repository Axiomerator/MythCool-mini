# 资源实测 · 2026-11-01

mini v0.2.0 在 Windows 11 x64、Ryzen 9 9950X（32 逻辑处理器）、RTX 3080 Ti、N360 上测量。当前六项配置为 CPU 最大线程占用、封装功耗、Tctl/Tdie 与 GPU 占用、功耗、核心温度。用户已确认注销后登录自启和冷头显示正常。

本次只读采样登录后的实际运行进程，60 秒、61 个采样点，未重启程序、裁剪工作集或减少指标。采样结束检查时状态窗口未显示；随后为 README 打开窗口截图。统计通过 Windows GetProcessTimes、GetProcessMemoryInfo(EX2)、GetProcessIoCounters 和 GetProcessHandleCount 取得。

| 指标 | mini 本次平均 | 最小～最大 |
| --- | ---: | ---: |
| 私有提交 | 28.70MiB | 28.65～29.83MiB |
| 私有工作集 | 26.02MiB | 25.89～27.18MiB |
| 总工作集 | 48.25MiB | 46.96～50.08MiB |
| 整机 CPU | 0.03174% | 60 秒累计 0.609375 CPU 秒，除以 32 个逻辑处理器 |

进程读/写各约 504B/s，其他 I/O 约 191B/s。这些计数包含 HID/USB 与驱动通信，不能当作磁盘读写速度。未单独测量 GPU 占用、能耗或驱动内核池内存。

## 原版对照

此前原版业务版本 1.1.22.420 的 5 秒进程组记录，包含 5 个 MythCool、HwMonitor64、GPP_USB_Center，共 7 个进程；本次 mini 为 1 个进程。

| 指标 | 原版历史 5 秒 | mini 本次 60 秒 | 记录对照 |
| --- | ---: | ---: | ---: |
| 私有提交 | 422.8MiB | 28.70MiB | 低 93.21% |
| 工作集求和 | 275.2MiB | 48.25MiB | 低 82.47% |
| 整机 CPU | 1.10% | 0.03174% | 样本值低 97.11% |

本机记录显示应用内存提交和 CPU 占用明显降低。原版样本较短、采样时段不同、窗口活动状态未完整记录，因此不能把百分比当作严格同条件的 A/B 性能基准或对所有硬件的保证。多进程工作集求和会重复计算共享页面，不等于实际减少的物理 RAM；私有提交也不是驻留内存。私有工作集更接近任务管理器的进程内存口径，原版该值未采集。

## 文件与复核

本机原版安装目录约 143.75MiB（77 文件），不含当前业务运行时；当前业务版本目录另约 147.42MiB（60 文件），未计个人素材、用户数据库及其他辅助组件。mini 的 EXE、DLL、签名模块约 0.87MiB，NVIDIA 与 PawnIO 系统依赖单列、不捆绑在应用中。

脱敏摘要为 [benchmarks/2026-11-01.json](benchmarks/2026-11-01.json)，不含 PID、用户路径或 SID。原始每秒记录留在本机 out/，不随仓库公开。复测命令见 DEVELOPMENT.md。早期开发的约 21.7MiB 私有提交 / 34.8MiB 工作集为另一短样本，当前报告使用此次登录后 60 秒数据。
