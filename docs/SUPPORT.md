# 支持范围

常驻续刷阶段可关闭原版；视频选择、导入、转码上传和布局编辑仍需 Myth.Cool。首次需要原版配置设备和用户数据库。mini 只读取原版数据库，在自己的副本上打开 LevelDB。

| 能力 | 状态 |
| --- | --- |
| VK N360，374A:A017 | 六槽续刷、视频持续播放和布局保持实机通过 |
| 亮度 0～100 | 实机验证 40→0→40，播放模式保持 |
| 默认管理员启动 | 清单和进程令牌已核验 |
| 当前用户登录自启 | 注册/移除及真实注销后登录均通过，用户确认 |
| AMD 9950X 温度/功耗 | Family 1Ah、Model 44h；签名 PawnIO 模块 |
| NVIDIA RTX 3080 Ti | NVML 占用、整卡功耗、核心温度 |
| Windows 11 x64 | 本机通过 |

仅识别 README 参数表中的原版英文指标键。CPU 最大线程占用与总占用分别实现。封装功耗采用 MSR 能量差分，与原版 SMU/HWiNFO 的口径可能有差异。显示值四舍五入到整数。

协议最多六槽；标题最多 9 个 UTF-8 字节、单位最多 5 字节、参数文本最多 5 字节。超限布局会报导入错误。自定义单位 type 0 和原版 type 1～13 已实现。未支持的指标显示 --，不替换为不同含义的数据。

其他型号/PID、其他 CPU 温度功耗、AMD/Intel GPU、多冷头、多显卡组合、Windows 10/ARM64 和非 Windows 系统未实现或未验证。同 Family/Model 的其他 CPU 及其他 NVML 显卡也需要验证后再列入支持表。睡眠/唤醒、长期运行、热插拔恢复和原版重新启动的完整交接仍需更多实测。

CPU 硬件读取依赖系统安装的官方签名 PawnIO 和管理员权限；NVML 来自现有 NVIDIA 驱动。应用不自动安装驱动，不携带厂商控制软件或 NVIDIA 驱动文件。
